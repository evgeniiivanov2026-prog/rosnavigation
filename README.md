# РосНавигация

Лендинг сети для дальнобойщиков России и СНГ. Девиз: «Своих не бросаем».

Статика без сборки: `index.html`, `css/styles.css`, `js/main.js`, шрифты в `fonts/`. Форум сюда не входит — это отдельный XenForo, см. [structure.md](structure.md).

## Локально

Из корня репозитория:

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

Откройте `http://127.0.0.1:8000`. Не открывайте `index.html` двойным щелчком: шрифты с `file://` браузер может заблокировать.

## Что поменять перед запуском

В начале `index.html` есть комментарий с адресами.

| Что | Где |
| --- | --- |
| Форум | все ссылки `https://forum.rosnavigation.ru` |
| Почта | `data-email` у `body`, `mailto:` у формы и ссылка в подвале |
| Formspree | атрибут `data-endpoint` у формы `#signup` |

Пока `data-endpoint` пустой, заявка не уходит на чужой сервер: скрипт открывает письмо в почтовой программе. Когда появится форма Formspree, вставьте её URL — тогда отправка пойдёт туда, а при ошибке останется запасной путь через почту.

Прямые ссылки разделов форума добавляйте после того, как узлы созданы. Каркас узлов — в `structure.md`.

## Изображения

Сейчас первый экран нарисован в вёрстке и весит мало. Живое фото усиливает его, но не обязательно для запуска.

Нужны такие кадры, если будете снимать своих, а не сток с улыбкой в чистой футболке:

1. Ночная фура сзади, свет габаритов, мокрый асфальт. Горизонтальный кадр от 2000 px, тёмный, без текста. Формат WebP, до 200 КБ. Положите в `images/hero.webp` и раскомментируйте правило в конце `css/styles.css`.
2. Картинка для соцсетей 1200×630, тот же сюжет, крупная надпись «РосНавигация» и строка «Своих не бросаем». Подключите её в `og:image`.
3. Стоянка и АЗС днём: видно, влезает ли фура. Для форума, не для первого экрана.
4. Деталь кабины, руки, зеркало. Без лиц, если человек не согласен на публикацию.

Не кладите на героя светлое фото: янтарные кнопки и белый текст на нём пропадут. Если фото светлее ночи, оставьте градиент из закомментированного правила.

## Shared-хостинг REG.RU

База и PHP лендингу не нужны. На хостинг кладутся только файлы. Форум XenForo в эту же папку не заливайте: для него позже заводится отдельный сайт `forum.rosnavigation.ru`.

Перед архивом в корне должны лежать рядом `index.html`, `css/`, `js/`, `fonts/`, `favicon.svg`, `robots.txt`. В архив не кладите папку `.git`. Упаковывайте содержимое корня, а не папку с проектом: после распаковки `index.html` обязан оказаться прямо в каталоге сайта. Если он окажется в подпапке `rosnavigation/index.html`, откроется заглушка хостинга.

1. В личном кабинете REG.RU домен привязан к услуге хостинга. Пока привязки нет, сайт с хостинга по этому имени не откроется. Смена DNS иногда занимает до суток, чаще — минуты, если NS уже реговские.
2. Откройте панель хостинга (кнопка у услуги). На новых тарифах это ispmanager. Реже cPanel или Plesk — корень сайта всё равно смотрите в карточке домена, не угадывайте `public_html`.
3. Раздел «Сайты» → ваш домен → «Файлы сайта». В ispmanager корень обычно `www/домен`. В cPanel колонка называется «Корень документа», в Plesk это каталог домена в «Сайты и домены» → «Менеджер файлов».
4. Удалите заглушку хостинга (`index.html`, `index.php` и прочие файлы парковки). Каталог `webstat`, если он есть, не трогайте.
5. «Загрузить» → zip-архив → «Извлечь». RAR панель Linux не распакует. После распаковки рядом с `index.html` должны быть папки `css`, `js`, `fonts`. Архив с сервера удалите.
6. В карточке сайта включите SSL (Let’s Encrypt) и перенаправление на HTTPS. `www` направьте на адрес без `www`, либо наоборот — один вариант, не оба сразу.
7. Почта: ящик `info@rosnavigation.ru`. Форма по умолчанию открывает письмо именно туда. Пока ящика нет, кнопка «Оставить заявку» соберёт текст, но доставить его будет некуда.

Проверка: откройте сайт не из панели, а по домену. Обновите с очисткой кэша. Если видите страницу REG.RU, в корне осталась заглушка или `index.html` лежит на уровень ниже. Если страница без стилей, не залили `css/` или `fonts/`.

Форум на том же хостинге — второй сайт в панели, каталог отдельный, PHP и MySQL по требованиям XenForo. Кнопки лендинга уже ведут на `https://forum.rosnavigation.ru`. Пока поддомена нет, они откроются только после того, как вы его создадите.

## Хостинг на своём сервере

Лендинг — это файлы. Отдельный CDN не обязателен: страница лёгкая, а часть внешних сетей на трассе открывается плохо. Поэтому шрифты лежат в репозитории.

DNS:

- `rosnavigation.ru` и `www` — на сервер со статикой. `www` перенаправьте на домен без `www`.
- `forum` — отдельная A-запись на сервер с XenForo, даже если это тот же IP. Корень сайта у форума другой.

Пример nginx только для лендинга:

```nginx
server {
    listen 443 ssl;
    http2 on;
    server_name rosnavigation.ru www.rosnavigation.ru;
    root /var/www/rosnavigation;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;
    }

    location ~* \.(css|js|svg|woff2|webp|jpg)$ {
        expires 7d;
        add_header Cache-Control "public";
    }
}
```

Сертификат — Let's Encrypt на оба имени. Форум настройте отдельным `server`: корень каталога XenForo, PHP, правила ЧПУ из поставки XenForo. Не проксируйте форум через папку лендинга и не открывайте его во фрейме.

Почту `info@rosnavigation.ru` заведите до того, как дадите ссылку людям: форма по умолчанию пишет именно туда.
