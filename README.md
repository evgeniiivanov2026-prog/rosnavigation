# РосНавигация

Сайт дальнобойного братства: [rosnavigation.ru](https://rosnavigation.ru). Девиз: «Своих не бросаем».

Форум сюда не входит. Это отдельный XenForo на [forum.rosnavigation.ru](https://forum.rosnavigation.ru), каркас узлов — в [structure.md](structure.md).

Стек под общий хостинг: PHP 8, MySQL через PDO, обычный JavaScript без сборки. Шрифты лежат в репозитории. Карта — Leaflet из `assets/vendor/leaflet`. Тайлы OpenStreetMap, ночной вид делается фильтром в стилях: публичный тёмный стиль Carto теперь отдаёт заглушку без ключа.

Пока нет боевой базы, сайт работает в демо-режиме и хранит данные в `storage/demo/db.json`. Этот файл в git не попадает и создаётся при первом заходе.

## Локально

Нужен PHP 8.1+ с расширениями `pdo_mysql`, `gd`, `mbstring`.

```bash
php -S 127.0.0.1:8765 router.php
```

Откройте `http://127.0.0.1:8765`. Встроенный сервер читает `router.php`, а не `.htaccess`.

Демо-вход, он виден на странице входа только в демо-режиме: телефон `+7 900 000-00-15`, пароль `kolonna15`.

## Перед боевым запуском

1. Скопируйте `inc/config.example.php` в `inc/config.local.php` или положите его на уровень выше корня сайта как `.env.php`. Оба пути в git не попадают.
2. Поставьте `APP_ENV` в `production`, заполните `DB_HOST`, `DB_NAME`, `DB_USER`, `DB_PASS`. Пустая база в production не пускает сайт.
3. Создайте базу и выполните `schema.sql`.
4. Каталоги `storage/cache`, `storage/logs`, `storage/backups`, `uploads/avatars`, `uploads/cars`, `uploads/channel` должны быть доступны PHP на запись. Внутрь них с веба заходить нельзя: это закрыто в `.htaccess`.
5. В панели хостинга включите HTTPS. Правило в корневом `.htaccess` само уводит с `http` на `https`. На локальном Apache без сертификата из-за этого сайт не откроется — для проверки используйте `php -S` и `router.php`.
6. Крон, раз в час, из каталога сайта:

```bash
php cron/cleanup.php
php cron/sitemap.php
```

`cron/backup.php` — дамп базы, по расписанию хостинга.

Демо-вход на бою не показывается. Пока `APP_ENV` не `production`, боевые данные не пишутся: сайт читает JSON.

## Хостинг REG.RU и аналоги

На хостинг кладётся содержимое корня, не папка с проектом. После распаковки `index.php` лежит прямо в каталоге сайта. Форум — второй сайт, отдельный каталог.

1. Домен привязан к услуге. Пока привязки нет, сайт по имени не откроется.
2. В панели откройте корень домена. В ispmanager это обычно `www/домен`. Смотрите карточку домена, не угадывайте путь.
3. Удалите заглушку хостинга. Каталог `webstat`, если он есть, не трогайте.
4. Загрузите zip и извлеките его. RAR панель не распакует. Рядом с `index.php` должны оказаться `css`, `js`, `fonts`, `inc`, `api`, `assets`, `templates`.
5. Создайте базу MySQL, импортируйте `schema.sql`, положите `config.local.php` по инструкции выше.
6. Включите SSL и одно перенаправление: либо на адрес без `www`, либо на адрес с `www`.
7. Почта: ящик `info@rosnavigation.ru`.

Проверка: откройте домен не из панели. Если видите заглушку хостинга, `index.php` лежит на уровень ниже. Если страница без стилей, не залиты `css/` или `fonts/`.

## Снимки

Живых фото в репозитории нет: на героя не кладём сток. Когда появятся свои кадры, WebP до 200 КБ кладите в `assets/img/hero`. Пока рассвет нарисован в вёрстке.

Картинка для соцсетей — `assets/img/og.png`, значки — `assets/img/icon-180.png`, `icon-192.png`, `icon-512.png`.
