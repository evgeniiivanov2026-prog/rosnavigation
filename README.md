# РосНавигация

Сайт дальнобойного братства: взаимная помощь на трассе, карта сигналов, партнёры и эфир. Девиз: «На 15-м — свои. Ты не один на трассе.»

Форум сюда не входит. Он остаётся отдельным XenForo на [forum.rosnavigation.ru](https://forum.rosnavigation.ru). Каркас разделов — в [structure.md](structure.md).

Сайт рассчитан на обычный shared-хостинг: Apache, PHP 8 и по желанию MySQL. Сборки, Node и Composer нет. Шрифты лежат в `fonts/`.

## Локально

Нужен PHP 8.1+ с расширениями `mbstring`, `gd`, `fileinfo`, `pdo_mysql`.

```bash
php -S 127.0.0.1:8080 router.php
```

Откройте `http://127.0.0.1:8080`. Пока база не настроена, данные живут в `storage/data.json`. Этот файл в git не входит.

Учебные карточки помечены «образец». Учебный сигнал нельзя принять: на него не едут. Это не служба спасения. Если жизни что-то угрожает, звонят 112.

Проверка сценариев без браузера:

```bash
php tests/smoke.php
```

## База

1. Импортируйте `sql/schema.sql` в phpMyAdmin.
2. Скопируйте `inc/config.local.example.php` в `inc/config.local.php` и впишите доступ к базе. Либо положите те же константы в `.env.php` на уровень выше корня сайта. Оба файла в git не попадают.
3. Пока `DB_HOST` и `DB_NAME` пустые или таблицы ещё нет, сайт работает на файле. Когда таблица `users` есть, чтение и запись идут только в MySQL. Учебные карточки в базу сами не попадают.

Пароли хранятся как Argon2id. Телефон виден хозяину профиля и тому, кто принял его живой сигнал.

## Хостинг REG.RU, Beget, Timeweb

Корень сайта — каталог с `index.php`. `index.html` быть не должно: иначе хостинг может отдать старую страницу.

1. Включите PHP 8.1 или новее и SSL. `www` направьте на адрес без `www`.
2. Залейте содержимое репозитория в корень сайта. Папку `.git` не заливайте. Каталоги `storage/` и `uploads/` должны быть доступны PHP на запись.
3. Импортируйте схему и создайте `inc/config.local.php`.
4. Почта: `info@rosnavigation.ru`.

Планировщик, раз в сутки, из каталога сайта:

```bash
php cron/cleanup.php
php cron/sitemap.php
php cron/partners_sync.php
```

`cron/backup.php` делает дамп базы, только если MySQL настроен. Пароль в командную строку не передаётся.

Чистые адреса (`/map`, `/sos`, `/partners`, `/channel`, `/auth`, `/profile/123`) включает `.htaccess`. На nginx те же пути нужно отдать соответствующим `*.php`.

## Что внутри

| Страница | Зачем |
| --- | --- |
| `/` | Первый экран, эфир, устав |
| `/sos` | Сигнал. Кнопку держат две секунды, с клавиатуры хватает Enter |
| `/map` | Карта и список. Без JavaScript список всё равно на месте |
| `/partners` | Каталог. У образца нет телефона и маршрута |
| `/channel` | Записи с трассы. Фото ждёт модератора |
| `/auth` | Имя, телефон, пароль, затем город и роль |
| `/profile` | Кабина. Чужой образец подписан |

Карта: Leaflet с unpkg и ночная подложка Esri World Dark Gray. У Carto тёмные тайлы без ключа теперь с водяным знаком, поэтому подложка другая. Кластеры и список не зависят от тайлов.

Опрос живых данных — обычный AJAX, раз в 15–30 секунд. Вкладка в фоне опрос останавливает. `manifest.webmanifest`, `sw.js` и `offline.html` держат короткую работу без сети.
